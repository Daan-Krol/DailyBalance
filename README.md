# Daily Balance / Payuung-Pribadi (prototype)
A very early-stage prototype for the Payuung Pribadi platform, developed by myself during my internship at Fast8 in Jakarta, Indonesia.
During my internship, I worked extensively with the Payuung Pribadi platform. As part of exploring and prototyping ideas for the platform, I created this small standalone prototype focused on a daily wellness and the "balance system", including daily activities, progress tracking, streaks, history, and a simple gamified tree system.

This prototype was designed and developed entirely by me as an early demonstration of how these concepts could work.

## Technologies
- Next.js
- TypeScript
- React
- Tailwind CSS
- shadcn/ui
- Phaser
- Zustand
- SQLite
- pnpm

## Features
- Daily activity tracking for water, exercise and rest
- Adjustable activity values
- Progress bars for daily goals
- Daily completion tracking
- 3-day activity history
- Daily login streak system
- Persistent data storage using SQLite
- Backend API for storing and retrieving daily data
- Basic gamification through a Phaser-based tree
- A simple dashboard interface inspired by the Payuung Pribadi concept

The backend is functional, with the application communicating with API routes that store and retrieve the user's daily activity data and streak information from the SQLite database.
